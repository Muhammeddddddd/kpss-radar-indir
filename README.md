# KPSS Radar — Android indirme

KPSS Radar, resmî kaynaklardaki kamu personel alım ilanlarını tek yerde toplayan bir Android uygulamasıdır. Bu depoda yalnızca uygulamanın kurulum dosyaları (APK) bulunur.

## İndir

**[KPSS-Radar.apk — son sürüm](https://github.com/Muhammeddddddd/kpss-radar-indir/releases/latest/download/KPSS-Radar.apk)**

Tüm sürümler: [Releases](https://github.com/Muhammeddddddd/kpss-radar-indir/releases)

## Kurulum

1. Yukarıdaki bağlantıya telefonundan dokun. GitHub hesabı gerekmez.
2. İndirme bitene kadar bekle. Dosya boyutu sürüm notunda yazar (yaklaşık 33 MB).
3. İndirilen `KPSS-Radar.apk` dosyasını aç ve **Yükle**'ye bas.
4. Android "bilinmeyen uygulamalar" izni sorarsa, indirdiğin tarayıcıya izin ver.

Eski sürüm yüklüyse üzerine kurulur; kayıtların silinmez.

## Bilgi

- KPSS Radar bağımsız bir ilan takip uygulamasıdır; hiçbir devlet kurumuna bağlı değildir.
- İlanlar SBB Kamu İlanları, Kariyer Kapısı, İŞKUR, Resmî Gazete, Yerel Yönetimler ve İlan.gov.tr'den okunur. Başvuru şartlarını her zaman ilanın kendi sayfasından kontrol et.
- Tercihlerin, takip listen ve notların yalnızca telefonunda saklanır.
